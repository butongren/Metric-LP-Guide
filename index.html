入门指南
01 / 选位置

Bin 是一格流动性

编号不是涨跌百分比。每格对应相对参考价的一段偏离；选中多格，就是给这些位置提供兑换资金。

02 / 看成交

活跃 Bin 是成交所在格

比较活跃 Bin 与所选范围，判断成交位置在区间内还是外。只有交易实际用到你的流动性，才产生 Edge。

03 / 跟参考价

区间会跟着参考价移动

它不是固定美元区间。仅参考价变化，不会触发换币，也不代表活跃 Bin 离开了所选范围。

相对活跃位置，资金在做什么？

所选格子在活跃位置下方

通常持有右币。卖单向下经过时，付出右币、买入左币。

所选范围覆盖活跃 Bin

活跃格通常含两币。范围内其他格不一定正在成交，不能把全部资金都当作正在赚取收益。

所选格子在活跃位置上方

通常持有左币。买单向上经过时，卖出左币、换回右币。

Edge、Trading P&L 和无常损失

Edge APR：成交价差收入年化。Trading P&L APR：相对一直持有原代币的交易盈亏年化，已经包含 Edge，不能把两者相加。

Trading P&L 为负，表示跑输持币；它不是未计收入的纯无常损失率，也不等于本金亏损率。例如换币与价格变化影响 −$10，Edge +$6，综合 Trading P&L 为 −$4。

来源、时间与计算口径

市场列表读取 Metric 官方公开 Metadata API，网络读取 Chains API，Bin 储备和收益读取官方前端使用的 Analytics/Bins API。接口无需账户、私钥或 API Key。本机每 30 秒请求一次；同时展示本机读取时间与上游统计时间，缓存和延迟单独标记。

列表 APR 使用 aprBps7d ÷ 100，代表过去 7 天的 LP Edge 收益年化，已按官方口径扣管理人和协议分成。Trading PnL APR 已包含 Edge，不可与 Edge APR 相加。24h Edge 和 APR 均直接读取 API，不从成交量和名义费率反推。

所选 Bin 配比按每个 Bin 的现有 token0/token1 储备比例计算，支持按储备价值分配和每 Bin 等额投入。空 Bin 的等额入场无法由储备确定，工具会提示。Bin 区间跟随参考价，不能用“涨过某个绝对价格就全部卖出”推算仓位。

九个时段采用固定 APR、单利情景，未模拟 Metric 实际复投、未来流量和稀释。涨跌测算以当前数据为假设入场点，不是钱包实际成本核算。单币配齐只是估算，工具不连接钱包或发送交易。
